# Insurance Premium Prediction

An end-to-end machine learning application that predicts an insurance premium category from user-provided details. The trained scikit-learn model is served through a **FastAPI REST API**, with a **Streamlit** interface for interactive predictions. The backend is containerized with **Docker** and deployed on **Render**.

## Live Demo

- **Streamlit application:** https://insurance-premium-frontend-rp1j.onrender.com/
- **FastAPI documentation:** Replace `YOUR_BACKEND_RENDER_URL` below with the actual URL of your deployed backend.
  - `https://YOUR_BACKEND_RENDER_URL/docs`
- **Health check:** `https://YOUR_BACKEND_RENDER_URL/health`

> The application is a portfolio/learning project. Predictions are model estimates, not official insurance quotes or financial advice.

## Project Overview

The project demonstrates how to take a trained machine learning model beyond a notebook and expose it through a usable web application. The API validates incoming data, derives model features, loads the saved model, and returns a predicted category with confidence and class probabilities.

## Features

- Predicts an insurance premium category using a trained scikit-learn classification model.
- Validates incoming request data with Pydantic.
- Derives features such as BMI, age group, lifestyle risk, and city tier from user inputs.
- Provides a FastAPI endpoint for predictions and a health-check endpoint.
- Returns the predicted category, confidence score, and probabilities for each class.
- Provides an interactive Streamlit frontend.
- Uses Docker to package the backend and Render to host the application.
- Exposes interactive API documentation through Swagger UI at `/docs`.

## Input Features

The frontend collects the following information:

| Input | Description |
|---|---|
| `age` | User's age in years |
| `weight` | Weight in kilograms |
| `height` | Height in meters |
| `income_lpa` | Annual income in lakhs per annum |
| `smoker` | Whether the user smokes (`true` or `false`) |
| `city` | User's city |
| `occupation` | Occupation category supported by the API |

The API derives additional model features from the input, including:

- `bmi` from weight and height
- `age_group` from age
- `lifestyle_risk` from smoking status and BMI
- `city_tier` from the configured city lists

The supported occupation values are `retired`, `freelancer`, `student`, `government_job`, `business_owner`, `unemployed`, and `private_job`.

## API Endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| `GET` | `/` | Returns a welcome message |
| `GET` | `/health` | Reports service status, model version, and whether the model is loaded |
| `POST` | `/predict` | Validates input and returns a premium-category prediction |
| `GET` | `/docs` | Interactive Swagger API documentation |

### Example prediction request

Send this JSON to `POST /predict`:

```json
{
  "age": 30,
  "weight": 65,
  "height": 1.7,
  "income_lpa": 10,
  "smoker": false,
  "city": "Mumbai",
  "occupation": "private_job"
}
```

### Example response structure

The values below are illustrative; the actual prediction and probabilities are generated by the deployed model.

```json
{
  "predicted_category": "medium",
  "confidence": 0.85,
  "probabilities": {
    "low": 0.10,
    "medium": 0.85,
    "high": 0.05
  }
}
```

## Run Locally

### 1. Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd <YOUR_REPOSITORY_DIRECTORY>
```

Replace the placeholders with the repository URL and directory name.

### 2. Create and activate a virtual environment

**Windows PowerShell**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**macOS/Linux**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Use a Python and scikit-learn version compatible with the environment used to train and serialize `model.pkl`. Scikit-learn models serialized with pickle may not be compatible across different library versions.

### 4. Start the FastAPI backend

From the repository root, run:

```bash
uvicorn app:app --reload --host 0.0.0.0 --port 8000
```

The API should be available at `http://localhost:8000`, with interactive documentation at `http://localhost:8000/docs`.

### 5. Start the Streamlit frontend

Open a second terminal, activate the same virtual environment, and run:

```bash
streamlit run frontend.py
```

The frontend must be configured to send requests to the backend at `http://localhost:8000/predict` for local testing. If `frontend.py` uses an environment variable for the API base URL, set `API_URL` to `http://localhost:8000` before starting Streamlit. For a production deployment, set it to your deployed backend's base URL instead.

## Run with Docker

Build the backend image from the directory containing the Dockerfile:

```bash
docker build -t insurance-premium-api .
```

Run the container:

```bash
docker run --rm -p 10000:10000 -e PORT=10000 insurance-premium-api
```

Then open `http://localhost:10000/docs`.

This command assumes the Dockerfile starts Uvicorn on the `PORT` environment variable (with `10000` as its fallback) and includes the model artifact and required application files in the image.
